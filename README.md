# primitive-db

Примитивная база данных с интерактивным интерфейсом командной строки. Метаданные таблиц хранятся в файле `db_meta.json`.

## Установка и запуск

Клонируйте репозиторий и перейдите в каталог проекта. Затем установите зависимости и запустите приложение:

```bash
uv sync
uv run database
```

Команда `uv sync` создаёт виртуальное окружение и ставит зависимости из `pyproject.toml`. После запуска программа ждёт команды. Справку можно вывести командой `help`, завершить работу — командой `exit`.

## Управление таблицами

Столбец задаётся в формате `имя:тип`. Допустимые типы: `int`, `str`, `bool`. При создании таблицы столбец `ID:int` добавляется автоматически.

### Команды

- `create_table <имя_таблицы> <столбец1:тип> [<столбец2:тип> ...]` — создать таблицу.
- `list_tables` — показать список всех таблиц.
- `drop_table <имя_таблицы>` — удалить таблицу (перед удалением запрашивается подтверждение).

### Пример использования

```text
Введите команду: create_table users name:str age:int active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, active:bool

Введите команду: list_tables
- users

Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]:y
Таблица "users" успешно удалена.
```

## CRUD-операции

Столбец `ID` заполняется автоматически и в команду `insert` не передаётся. Остальные значения указываются в том же порядке, что и столбцы при создании таблицы. Числа пишутся без кавычек, логические значения — `true` и `false`.

### Команды

- `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — добавить запись.
- `select from <имя_таблицы>` — показать все записи.
- `select from <имя_таблицы> where <столбец> = <значение>` — показать записи по условию.
- `update <имя_таблицы> set <столбец> = <новое_значение> where <столбец_условия> = <значение_условия>` — обновить записи.
- `delete from <имя_таблицы> where <столбец> = <значение>` — удалить записи (перед удалением запрашивается подтверждение).
- `info <имя_таблицы>` — показать столбцы и количество записей.

## Обработка ошибок и подтверждение действий

Опасные и нештатные ситуации обрабатываются декораторами из `decorators.py`, поэтому CLI не падает с traceback, а выводит понятное сообщение и продолжает работу.

### Обработка ошибок

Декоратор `handle_db_errors` перехватывает типичные исключения при работе с таблицами и данными:

- отсутствует файл данных;
- таблица или столбец не найдены;
- некорректные значения (валидация типов и количества полей).

```text
Введите команду: create_table users name:str age:int active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, active:bool

Введите команду: create_table users name:str
Ошибка: Таблица или столбец users не найден.

Введите команду: drop_table products
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]:y
Ошибка: Таблица или столбец products не найден.
```

### Подтверждение действий

Декоратор `confirm_action` запрашивает подтверждение перед удалением таблицы (`drop_table`) и перед удалением записей (`delete`). Ответ `y` выполняет действие, любой другой — отменяет его.

```text
Введите команду: delete from users where name = Bob
Вы уверены, что хотите выполнить "удаление данных из таблицы"? [y/n]:n
Действие отменено.

Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]:n
Действие отменено.

Введите команду: list_tables
- users

Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]:y
Таблица "users" успешно удалена.
```

### Замер времени

Декоратор `log_time` выводит время выполнения для операций `insert` и `select`:

```text
Введите команду: insert into users values (Alice, 30, true)
Функция insert выполнилась за 0.001 секунд.
Запись с ID=1 успешно добавлена в таблицу "users".
```
